# Скрипт таблицы: установка (только в ТЕСТОВУЮ копию)

Таблица: «ТЕСТ OzonBooks (для приложения размещения, не боевая)». В боевую OzonBooks не ставим до пилота.

## 1. Лист «Остатки 1С» (для режима «Где книга?»)

1. Откройте тестовую таблицу → **Файл → Импорт → Загрузить** → файл `1C на 04.11.xlsx`.
2. «Место импорта»: **Вставить новые листы** → «Импортировать данные».
3. Переименуйте появившийся лист в **`Остатки 1С`** (правый клик по вкладке → Переименовать).

## 2. Скрипт

1. В тестовой таблице: **Расширения → Apps Script**.
2. Удалите всё в файле `Код.gs` и вставьте целиком содержимое `Code.gs`. Сохраните (значок дискеты).
3. Вверху выберите функцию **`setup`** → **Выполнить**. Google попросит разрешения — разрешите
   (аккаунт ваш, скрипт работает только с этой таблицей).
4. Откройте **Журнал выполнения** внизу: там будут две строки вида `Ольга: 5f3c…` и `Влада: 9a1e…` —
   это ключи для телефонов. Пришлите их мне **личным сообщением сюда не нужно** — они вводятся
   в приложение на телефоне один раз.
5. В листе «Лист1» появятся столбцы «Артикул», «Упаковка», «Размещено», «Размещено кем»,
   и новые листы «Журнал размещения» и «Ошибки».

## 3. Публикация как веб-приложение

1. **Развернуть → Новое развертывание** → тип «Веб-приложение».
2. «Выполнять как»: **Я**. «У кого есть доступ»: **Все**.
   (Без ключа устройства скрипт ничего не отдаёт и не принимает.)
3. **Развернуть** → скопируйте **URL веб-приложения** (заканчивается на `/exec`) и пришлите мне.

## Что скрипт делает и чего не делает

- Пишет только в «Место хранения», «Артикул», «Упаковка», габариты, «Размещено», «Размещено кем»
  листа «Лист1». Архив и «Остатки 1С» только читает.
- Артикул создаёт один раз (`ячейка_штрихкод`) и больше не меняет, даже при перемещении.
- Каждый пик сначала пишется в «Журнал размещения»; повторная отправка того же пика пропускается.
- Всё, что не удалось применить (неизвестный штрихкод, книга уже на другой полке, дубль штрихкода),
  попадает на лист «Ошибки».
